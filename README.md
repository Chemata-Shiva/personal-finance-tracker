# Personal Finance Tracker

## 📌 Project Description

Personal Finance Tracker is a Python-based application designed to help users manage and track their personal financial information in an organized way.

## ✨ Features

- Add income details
- Add expense details
- Track financial transactions
- Calculate income and expenses
- Monitor savings
- Simple and user-friendly interface
- Organized financial record management

## 🛠️ Technologies Used

- Python
- MySQL

## 🎯 Project Objective

The main objective of this project is to provide a simple way to manage personal income, expenses, and savings while improving practical programming and database skills.
